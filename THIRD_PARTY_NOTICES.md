# Third-party notices

## Project scaffold

The initial module skeleton and root Apache-2.0 license file were generated by the official `moon new` command from MoonBit toolchain `0.1.20261023`. The generated scaffold is retained as project setup; the MoonBridge implementation is authored in this repository.

## Runtime dependency

- [`moonbitlang/async` 0.22.5](https://mooncakes.io/docs/moonbitlang/async): Apache-2.0. Used by the MoonBit CLI for native file-system operations. The dependency is declared in `moon.mod`; its source is fetched by Mooncakes into an ignored cache and is not copied into the project.
- The Linux `.a` and `.so` produced by `scripts/package-linux.sh` include MoonBit-generated code and MoonBit runtime objects. The shared-library packager recompiles runtime C files from the installed MoonBit toolchain as PIC. Those runtime source files carry Apache-2.0 headers; they are consumed from the local toolchain and are not vendored into this repository. Retain this notice and the upstream Apache-2.0 license when redistributing generated libraries.
